API Documentation

Open API • No Authentication Required

Use the end.lat API in your web apps, Discord bots, or multiplayer games to create shareable short links on the fly. CORS is enabled for all domains.

Endpoint
GET https://end.lat/api?url={URL}&keyword={KEYWORD}
Party / Room Sharing Example

When a player creates a game room or party, generate a clean link to share around with friends:

const roomUrl = "https://mygame.io/rooms/party-9821"; const res = await fetch(`https://end.lat/api?url=${encodeURIComponent(roomUrl)}&keyword=squad-party`); const data = await res.json(); console.log(data.short); // https://end.lat/squad-party
One-Click Direct Redirect

Pass redirect=true to instantly redirect users to their new short link:

<a href="https://end.lat/api?url=https://mygame.io/party/123&redirect=true"> Create Short Party Link </a>
Parameters
Parameter Type Description
url string Required. The destination http(s) URL.
keyword string Optional. Custom slug (alphanumeric, -, _).
redirect boolean Optional. If true, 302 redirects to the new short link.
cURL Example
curl "https://end.lat/api?url=https://mygame.io/rooms/party-9821&keyword=squad-party"
